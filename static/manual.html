01考え方

これまでの ToDo アプリが続かなかった理由は、「書くのが面倒」「何の件か忘れる」「機能が多すぎる」の3つでした。gototask はそこを避けるように作っています。

書くのは Claude

会話で「終わった」「〇〇さんに頼んだ」と言えば、Claude がタスクを直します。

背景が付いている

どのタスクにも、元の資料やメールへのリンクとノートが付きます。

中身はただのテキスト

プロジェクトごとの TASKS.md。Obsidian の Tasks と同じ書き方なので、Obsidian でもそのまま開けます。

02画面

ブラウザで http://localhost:8765/ を開きます。PC を起動すると自動で動いています。

上の追加欄
どの画面でも1行で追加できます（/ で移動）。書き方は次の節。
今日
最初に開く画面。大きく出る「いまやる」1件と「つぎ」、前の日からの「持ち越し」。右の列に「待ち」「今日片付いた」「新着」。
待ち
@名前 が付いたもの。人ごとにまとまります。
優先
優先の印（⏫）が付いたもの。
すべて
プロジェクトを1行ずつ一覧。並び順は残りの多い順・期限の近い順・名前順から選べます。残りの無いプロジェクトは最後に畳んであります（上の「# プロジェクト」の一覧も同じ）。
週報
範囲（プロジェクトの束）と週を選ぶと、プロジェクトごとに「済んだ」「進んだ」「新しく入った」「来週の期限」「期限切れ」「待ち」を並べます。「材料をコピー」で Markdown に、「AI に頼む文をコピー」で、AI に週報を書いてもらう文ごとコピーします。範囲は「設定」で決めます（例：1課: 営業A, 営業B／営業部: 1課, 2課）。
AI に頼む（右上）
議事録からの更新・今日の記録・残りの点検・繰り返しの登録など、AI に渡す決まった文をコピーできます。
# プロジェクト ▾
押すと（または p）プロジェクトの一覧が開き、名前で絞り込めます。プロジェクトが増えてもここ1か所で切り替えます。入れた言葉でタスクも探せます（一番下の「タスクを探す」。タイトル・担当・ノート・子タスク、済んだものも対象）。

文字が小さいときは、右上の「A− A＋」で 85〜160% に変えられます。ブラウザが覚えています。右上の点は Google ToDo との同期状態（緑＝正常）。

04右の詳細パネル

タスクの「裏の1枚」です。何の件か、どこまで進んだかをここに残します。

  • 期限：日付を選ぶとすぐ保存。「消す」で外します。
  • 今日：☀ で今日やるに入れる／外す。
  • 繰り返し：毎日・平日・毎週・隔週・毎月・毎月末・毎年から選びます。済にすると、期限を同じだけずらした次の回がすぐ下にできます（毎週なら期限の曜日のまま）。
  • 子タスク：下の欄に書いて Enter で追加（押印申請 期限10/15 のように期限も付けられます）。□ で済。進み具合はタスクの行に「子 2/5」と出ます。
  • タイトル・担当を変える：タイトルの書き換え。@名前 を足したり消したりして担当を付け替えます。
  • 背景・出典：元の資料へのリンク。PC のファイルは「nvim」で gototerm の新しいタブに開きます。
  • ノート：Markdown で書けます。「ノートを書く」から保存。
  • やらない：やらないと決めたもの。済とは分けて残ります。
  • 削除：間違えて作ったときだけ。data/trash.md に残ります。
  • 右上の TASKS.md:12：そのタスクの行を gototerm の nvim で開きます。

05プロジェクトと区分

1つのフォルダ＝1つのプロジェクトです。フォルダ直下の TASKS.md がそのプロジェクトのタスクになります。

  1. プロジェクトを足す：そのフォルダで gtask init。TASKS.md ができて登録されます。gtask init --agents にすると、CLAUDE.md（または AGENTS.md）に「残タスクは TASKS.md に書く」と1節足し、以後は Claude Code も Codex も同じファイルを読み書きします（既定では書き換えず、足す内容を表示するだけ）。
  2. 区分を足す：プロジェクトのいちばん下の「＋ 区分を追加」。中身は ## 見出し です。
  3. 区分の名前を変える・消す：見出しの右端の「⋯」から。消しても中のタスクは「区分なし」へ移ります。
  4. プロジェクトの名前を変える：プロジェクト画面の上、ファイルの場所の右の「⋯」から。中身は # 見出し です（受信箱は変えられません）。
  5. 済んだものを見る：プロジェクト画面と人の画面の「済も表示」をオンにすると、済・やらないが終わった月ごとに出ます。期間は今月・この3か月・今年・去年・すべて・日付を指定から選べます。人の画面では、件数・プロジェクト別・月別のまとめと「Markdownでコピー」が出ます。件数は目安です（子タスクだけ済んだものは数えず、平均日数は作ってから済むまでの日数で、作業時間ではありません）。新しく足したタスクには作った日（➕）が付き、済むまでの平均日数も出ます。
  6. 人ごとに見る：上の「@ 人」から選ぶと、その人に頼んでいるタスク（@名前）がプロジェクトごとに出ます。「待ち」の名前を押しても同じです。
  7. よく見るプロジェクトを上のタブに出す：同じ「⋯」の「上のタブに出す」。今日・待ち…の横に並び、1回で開けます。外すのも同じ場所から。
  8. タスクを別のプロジェクト・区分へ移す：タスクの詳細の「別のプロジェクトへ移す」。子タスク・ノート・背景ごと移ります。
  9. まとめて振り分ける：Obsidian から読み込んだタスクなどは、Claude Code に「プロジェクトに振り分けて」と頼むと、案を表で出してから移します。

どのプロジェクトにも入らないもの（受信箱・会社など）は gototask の data/TASKS.md に入ります。

06Claude との分担

あなた

見る・チェックする・☀ を付ける。思いついたら会話で話す。

Claude

会話からタスクを足す・直す・済にする。背景のリンクとノートを付ける。

資料（backlog など）

「なぜやるか」の正本。済・やらないは Claude が自動で書き戻します。

こう話せば伝わります

  • 「残タスク見せて」「〇〇終わった」「〇〇は山田さんに頼んだ」「それはやらない」
  • 「メール見て」…受信トレイからタスクの候補を出します。Gmail を自動で読むことはしません。

週報のために

議事録や1日の作業を AI に渡すと、済んだものは ✅、進んだことはタスクの下に - 2026-10-16 見積案を提出 のような1行（経過）で残ります。週報の画面は、この経過と ✅ の日付から材料を作ります。決まった頼み方は、右上の「AI に頼む」にあります。

07スマホ（Google ToDo）

「今日」の画面に入ったタスクが、Google ToDo アプリの 「gototask 今日」 リスト（許可した Google アカウント）に出ます。

スマホで完了
gototask でも済になります。
スマホで追加
gototask の受信箱に「今日やる」として入ります。
スマホで削除
その日は送り直しません。
同期のタイミング
5分ごと＋gototask で操作した直後。右上の点にマウスを乗せると最後の同期時刻が出ます。

送られるのは「今日」のタスクだけです。家庭用のリストとは混ざりません。

08ターミナルと gototerm

ターミナルでは gtask で同じことができます。番号は gtask ls に出る番号です。


      

        
gtask init
今いるフォルダに TASKS.md を作ってプロジェクトに登録。--agents で CLAUDE.md / AGENTS.md に使い方も足す。

        
gtask ls [名前]
未完了の一覧。プロジェクト名の一部で絞れます。

        
gtask add "…" [-p 名前/区分]
追加。省略すると今いるフォルダのプロジェクトへ（無ければ受信箱）。

        
gtask today [N]
今日の一覧／N番を今日やるに（--off で外す）。

        
gtask done / drop / del N
済／やらない／削除。

        
gtask show N
背景とノートを表示。

        
gtask open [--all]
今いるフォルダのタスクをブラウザで開く。

        
gtask gsync [--auth]
Google ToDo と今すぐ同期（--auth は許可の取り直し）。

      

      
gototerm

      
    
        
  • タブバーの右端に 残N 優先M が出ます。
    • 
        
  • Ctrl + Shift + G で、今いるフォルダに関係するタスクを開きます。
    • 
        
  • タブバーの「残N 優先M」は、今いるフォルダの TASKS.md の数です（無ければ受信箱のファイル）。
    • 
        
  • サイドバーの [tasks]（Ctrl+Shift+H でサイドバーに入り、Tab で切り替え）に、今いるフォルダの TASKS.md の残りが出ます。l でその行をエディタで開き、x で済にします。

10困ったとき

      

        
画面が開かない
Windows は gototask.pyw をダブルクリック。Mac・Linux は gtask serve（動いていればブラウザで開くだけ）。Linux の自動起動は systemctl --user restart gototask

        
PC の起動時に立ち上げたい
gtask autostart on（やめるときは off）。初回の設定画面でも選べます。

        
Obsidian のタスクを読み込みたい
初回の設定画面で保管庫を選ぶと、未完了の - [ ] をノートごとに並べて「読み込みますか」と聞きます。元のノートは書き換えず、背景: 付きで写します（済にしてもノートには書き戻しません）。プロジェクトは、フォルダ（1〜3階層目）・タグ（例：#案件/A社 の「A社」）・ノートのプロパティ（例：project）のどれで分けるかを選べます。分け方を変えると、どのプロジェクトに何件入るかがその場で出ます。あとからでも localhost:8765/setup で同じ手順をやり直せます（同じタスクは二重になりません）。

        
右上の点が黄色（許可が切れた）
gtask gsync --auth で、Google アカウントを選び直して許可。

        
名前・アイコンを変えたい
右上の「設定」で、画面の名前と、アイコン（フラスコ／シンプル）を変えられます。その PC だけの設定です。

        
「保存しませんでした」と出た
画面を開いた後に、AI などが同じタスクを書き換えていました（古い画面のまま保存して、AI の書き足しを消さないためです）。ノートを書いていた場合は、書いた文が下に残っているので、コピーしてから最新の内容に貼り直してください。

        
Obsidian を使っていない
そのままで使えます。初回の画面で「この PC の中だけで始める」を選び、今あるやることを1行ずつ貼ると、そのまま入ります。

        
消したタスクを戻したい
data/trash.md に残っています。Claude に「戻して」と言えば戻します。

      

      
わからないことは、Claude に「gototask の〇〇どうやるの？」と聞いてください。
