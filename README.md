# gototask

AI が書いて、人は見るだけの ToDo です。

タスクは Markdown のファイル `TASKS.md` に書かれます。Claude Code や Codex に「議事録から足して」「これ終わった」と頼むと、AI がこのファイルを直します。人はブラウザの画面（`http://localhost:8765/`）で見て、済にしたり、期限を変えたりします。

- **書くのは AI**：議事録・メール・1日の作業を渡すと、タスクの追加・済・経過の記録までまとめて直します。画面の「AI に頼む」に、決まった頼み方を置いてあります。
- **週報の材料が自然にたまる**：済んだ日（✅）と、タスクの下の経過（`- 2026-10-16 見積案を提出`）から、週ごと・範囲ごと（チーム・課・部）に材料を並べます。
- **中身はただのテキスト**：[Obsidian Tasks](https://publish.obsidian.md/tasks/) と同じ書き方です。Obsidian が無くても使えます。
- **PC の中だけで動く**：外部のサーバーには送りません。Python の標準ライブラリだけで動きます。

## 使い始める

### Windows（Python 不要）

[Releases](../../releases) から `gototask.exe` をダウンロードして、ダブルクリックします。ブラウザで初回の画面が開きます。

設定やタスクは `%APPDATA%\gototask` に保存されます。

### Python がある PC（Windows・Mac・Linux）

```sh
git clone https://github.com/mamagotolab/gototask.git
cd gototask
python3 serve.py --open        # Windows は gototask.pyw をダブルクリックでも可
```

`gototask`（コマンド）を PATH に置くと、ターミナルでも `gtask ls` / `gtask add "…"` / `gtask done 3` などが使えます。名前は `gtask` にして使う想定です。

### 初回の画面

1. タスクを置く場所を選びます。「この PC の中だけで始める」か、プロジェクトのフォルダ（Obsidian の保管庫も可）です。
2. 今あるやることを1行ずつ貼り付けると、そのまま入ります（`@山田さん`、`期限10/20`、`毎週金曜` なども読み取ります）。
3. Claude Code・Codex が入っていれば、フォルダの `CLAUDE.md` / `AGENTS.md` に使い方の1節を足せます。

## 書き方

```markdown
# プロジェクト
## 区分
- [ ] 見積もりを送る @山田さん ⏫ ➕ 2026-10-13 📅 2026-10-20
  背景: 議事録/2026-10-13.md:12
  - [ ] 押印申請 📅 2026-10-15
  - 2026-10-16 見積案を提出。先方の確認待ち
- [ ] 週報を出す 🔁 every week on Friday 📅 2026-10-23
- [x] 済んだタスク ✅ 2026-10-11
- [-] やらないと決めたタスク ❌ 2026-10-11
```

| 印 | 意味 |
|---|---|
| `@名前` | 頼んだ相手（「待ち」と人ごとの画面に出ます） |
| `⏫` | 優先 |
| `➕` `⏳` `📅` | 作った日・今日やる日・期限 |
| `✅` `❌` | 済んだ日・やめた日 |
| `🔁 every …` | 繰り返し。済にすると次の回がすぐ下にできます |
| `- 日付 内容`（字下げ） | 経過。週報の「進んだ」に出ます |

詳しい使い方は、画面右上の「使い方」にあります。
